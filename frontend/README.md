# Weekly Lesson Planner frontend

Angular 22 standalone application using Angular Material and CDK.

## Local commands

Requires a Node version supported by Angular 22 (the stack build uses Node 24).

```bash
npm ci
npm start
npm test
npm run build
```

`npm start` proxies `/api` and `/health` to the backend at `http://localhost:5080`.
Production traffic is served and proxied by the Nginx container defined under `../stack`.

The Phase 2 screen manages the inclusive planning range, visible weekdays and colors, course weekdays, global holidays/events, and course exams. Its school-year grid is generated by the backend using ISO 8601 weeks; selecting a course reveals only that course's exam markers and teaching days.

Phase 3 adds shared topic-definition management and an alphabetically ordered, searchable list containing only unplanned topic instances. Editing an instance edits its shared definition; deleting an instance removes only that occurrence.

Management is organized into tabs. Course and topic saves show a top-position notification, newly created topics refresh directly into the unplanned list, and the calendar's **All topics** view includes placed topics from every course with course labels.
